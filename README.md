# 🛡️ PayGuard AI - Fraud Detection System

An AI-powered fraud detection platform that classifies financial transactions into:

- Fraud
- Suspicious
- Legitimate

using Machine Learning and Streamlit.

---

## 🚀 Overview

PayGuard AI provides real-time transaction risk prediction with:

- Fraud probability analysis
- Risk classification
- AI-based recommendations
- Interactive dashboard
- Transaction monitoring

---


## 🧠 Machine Learning Pipeline

- Data preprocessing
- Feature selection
- Leakage feature removal
- Categorical encoding
- Feature scaling
- XGBoost model training
- Model evaluation
- Real-time prediction

---

**Programming**

**Machine Learning**

## 📊 Model Performance

**Model:** XGBoost Classifier

- Accuracy: 96%
- Fraud Recall: 86%
- ROC-AUC: 98.7%
